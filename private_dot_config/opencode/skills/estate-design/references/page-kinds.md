# Page kinds and section anatomy

Declare the kind on the page and let it drive structure, imagery, and the
motion budget. `<html data-type="…">` + `<meta name="site-kind" content="…">`.

## The kind table

| Brief | data-type | site-kind |
|---|---|---|
| App, SaaS, AI, dev tool, fintech app, studio selling its own software | software | software |
| Game or game studio | software | gaming |
| Hardware / tech device | product | tech |
| Other physical product sold online | product | other |
| People are hired (clinic, law firm, agency, studio, trade) | service | other |
| People come to it (cafe, shop, hotel, gym, restaurant) | place | other |

A maker with a door (bakery with a web shop) is a **place**; its shop is a
section. It is a **product** only when nothing happens at the door.

Effects, scenes, shader moments, dark heroes: **software/gaming/tech only**.
Places and services: photography (12–20 images on a full page), flat color,
type, real icons, the hover layer — no effect layer.

## Primary verb orders the sections

Derive the page's one primary verb and let it sequence the page:

- **try** (app, tool): hero with live demo → how it works → proof → start.
- **buy** (physical product): product renders → details/specs → offer →
  order path.
- **book / visit** (clinic, restaurant, venue): photographs lead → what
  awaits (visit block on screen two) → offer → booking/contact.
- **hire** (studio, freelancer): work samples → proof of people → process →
  contact.
- **sign up** (software, API): hero → concrete capability → proof → plan.
- **join** (community, membership): who it is for → what happens inside →
  join path.
- **subscribe / attend**: the offer up front → schedule/content → commit.

## Section discipline

- Hero alone on the first screen; each section one to two screens tall at
  1440×900.
- Equal left and right content edges across the page.
- Variety between sections comes from structure and imagery, not from
  per-section effects or animations.
- Every image, at every width, renders — no empty ground, ever.

## Copy per kind

Places write in the visitor's senses ("the room is quiet by 22:00");
software writes in the operator's outcomes ("deploys in under a minute");
services write in the client's decision ("fixed-fee, scoped in one call").
Never invent numbers, names, or counts: if a fact is missing, structure the
section so it works without it.
